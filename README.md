# 🧠 LifeBoard

A personal life task board — ADHD-friendly scheduling powered by algorithms from *Algorithms to Live By*.

## Features
- 8 life areas (Work, Growth, Health, Relationships, Finances, Recharge, Home, Future)
- WSPT priority scoring (mathematically optimal scheduling)
- Task dependencies, time windows, recurring tasks
- Brain Dump inbox, Focus Mode (Pomodoro), Rescue Mode
- Moore's Triage algorithm
- 🔐 PIN lock for privacy

## Tech
Single self-contained HTML file. All data in localStorage. No backend.

## iPhone
Open in Safari → Share → Add to Home Screen → use as a native app.
